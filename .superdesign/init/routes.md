# Route map

Framework: Next.js 16.3 App Router, React 19.2, TypeScript.

- `/` → `src/app/page.tsx`, cinematic landing page with `SiteHeader` and `ScenePicture`.
- `/studio/basic` → `src/app/studio/basic/page.tsx`, currently a placeholder for the professional workspace.

Planned prototype routes: `/checkout`, `/projects`, `/projects/[projectId]`, `/account`, and a route-backed mocked sign-in experience.
